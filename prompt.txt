Advanced Tic-Tac-Toe Game — HTML, CSS & JavaScript

Create a complete, modern, responsive Tic-Tac-Toe game using only HTML, CSS, and vanilla JavaScript. Do not use React, Bootstrap, Tailwind CSS, jQuery, or any external framework/library.

1. Project Structure

Create the project with these files:

index.html
style.css
script.js

Keep HTML, CSS, and JavaScript separated properly.

2. Game Concept

Build a classic 3×3 Tic-Tac-Toe game where two players take turns.

Player 1 uses X
Player 2 uses O
Players click an empty cell to place their symbol.
X always starts first.
A player wins when they get three matching symbols in:
Horizontal row
Vertical column
Diagonal

Example winning combinations:

[0, 1, 2]
[3, 4, 5]
[6, 7, 8]

[0, 3, 6]
[1, 4, 7]
[2, 5, 8]

[0, 4, 8]
[2, 4, 6]

7. Winning Animation

When a player wins:

Highlight the three winning cells.
Add a smooth animation.
Display a message such as:
🎉 Player X Wins!

or:

🎉 Player O Wins!

The winning cells should visually stand out from the rest of the board.

8. Draw Condition

If all nine cells are filled and nobody wins:

Display:

🤝 It's a Draw!

Do not allow additional moves after the draw.

9. Score System

Maintain scores during the current browser session.

Example:

Player X       Player O
   3              2

When X wins:

scoreX++;

When O wins:

scoreO++;

The score should remain unchanged when a game ends in a draw.

10. Restart Round Button

Add a button:

Play Again

When clicked:

Clear the board.
Reset all cells.
Set X as the starting player.
Set gameActive = true.
Remove winning animations.
Update the turn indicator.

Important:

Do not reset the scores when Play Again is clicked.

11. Reset Game Button

Add another button:

Reset Game

This button should:

Clear the board.
Reset Player X score to 0.
Reset Player O score to 0.
Set X as the starting player.
Reset the game completely.

Ask for confirmation before resetting the complete score.

Example:

confirm("Are you sure you want to reset the entire game?");

13. Responsive Design

The game must work properly on:

Desktop
Laptop
Tablet
Mobile phone

Use CSS media queries.

On mobile:

Reduce board size.
Make buttons easy to tap.
Keep the player cards readable.
Prevent horizontal scrolling.

Example:

@media (max-width: 600px) {
    .game-board {
        width: 300px;
        height: 300px;
    }
}

Make the game accessible.

Each cell should be a <button> rather than a generic <div> whenever possible.

Add useful attributes such as:

Buttons should be keyboard accessible.

Use visible focus styles.

Make sure the text has sufficient contrast against the background.
